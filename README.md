# 📝 BlogTown

A modern and responsive blogging platform built with **React**, **TailwindCSS**, and **Markdown** support.  
Easily create, manage, and showcase blogs with a clean UI and engaging features.

---

## 🚀 Features

- 🎨 **Modern UI/UX** – Fully responsive design with TailwindCSS.  
- 🔍 **Search Functionality** – Quickly find blogs using keywords.  
- 🌟 **Featured Posts** – Highlight the best or latest blog post.  
- 📑 **Markdown Support** – Write blogs in markdown format for simplicity.  
- 📰 **Blog Cards Layout** – Grid-based preview cards for quick browsing.  
- 📬 **Newsletter Subscription** – Simple subscription form to capture readers.  
- 🖼️ **Logo & Branding** – Custom logo with brand name integration.  
- ⚡ **Fast Performance** – Built on React’s component-driven architecture.  

---

## 🛠️ Tech Stack

- **Frontend:** React.js, TailwindCSS  
- **Routing:** React Router  
- **Icons:** Lucide React  
- **Markdown Rendering:** (planned / optional)
